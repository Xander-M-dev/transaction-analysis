# Приложение для анализа транзакций

Приложение для анализа банковских транзакций из Excel-файлов с возможностью генерации отчетов, JSON-ответов для веб-страниц и предоставления различных сервисов.

##  Функциональные возможности

- **Веб-страницы**: Генерация JSON-ответов для главной страницы
- **Сервисы**: Простой поиск по транзакциям
- **Отчеты**: Анализ трат по категориям
- **Интеграция с API**: Получение курсов валют и цен на акции
- **Логирование**: Ведение журнала операций
- **Тестирование**: Полное покрытие кода тестами

# Использование

### Запустите главный модуль
python src/main.py

# Форматирование кода

### Форматирование с помощью black
poetry run black src/ tests/

### Сортировка импортов
poetry run isort src/ tests/

### Проверка стиля
poetry run flake8 src/ tests/

### Проверка типов
poetry run mypy src/

# Тестирование

### Запуск всех тестов
poetry run pytest tests/ -v

### Запуск с измерением покрытия
poetry run pytest tests/ --cov=src --cov-report=term-missing

### Генерация HTML отчета покрытия
poetry run pytest tests/ --cov=src --cov-report=html

## Проект использует следующие подходы к тестированию:

Модульные тесты: Проверка отдельных функций

Mock-объекты: Изоляция от внешних зависимостей

Параметризация: Тестирование с различными входными данными

Фикстуры: Повторное использование тестовых данных
